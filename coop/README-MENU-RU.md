# «Совместная игра» в главном меню — r8

Кнопка добавляется в штатный список главного меню под «Выход». Страница настроек находится в том же дереве UMG и заменяет содержимое списка; отдельного окна и панели поверх игры нет. Первая версия рассчитана на мышь и клавиатуру, F-14D и задание 6 сборки 25201480.

## Запуск

1. Распакуйте весь комплект в отдельную папку. Запустите Steam и `Start-Coop.cmd`; при первом запуске укажите папку игры. Окно запуска оставьте открытым до выхода из игры. Python и Visual Studio для запуска не нужны.
2. Откройте «Совместная игра» в главном меню. Выберите «Создать сессию» или «Присоединиться», введите SteamID64 другого участника, нажмите «Подтвердить настройки». Роль и ID сохраняются только на этом ПК.
3. Оба выбирают «Готов — автоматический старт». Затем обычным способом откройте задание 6, выберите F-14D и одинаковое вооружение/детали. Автоматическая загрузка задания и установка самолёта из этой страницы ещё не реализованы; отображаемые задание и самолёт фиксируют допустимый вариант.
4. В активном полёте поддерживаемого задания мод сам снимает состояние, проверяет исходный самолёт, устанавливает связь, дожидается свежих согласованных данных второго участника и разрешения обоих. F8/F7 и внешний Review-And-Arm не нужны. Если проверка не пройдена, копия не создаётся. Начинайте подготовку одновременно: ожидание второго участника после полётной проверки ограничено 90 секундами.
5. Первый сетевой опыт сохраняет предел 15 секунд и тестовое смещение копии на 300/100/20 метров по мировым осям. F9 остаётся аварийной остановкой в полёте. В меню также есть «Остановить совместный опыт». Повторного создания в одном процессе нет: для повтора штатно закройте игру и запустите комплект снова.

## Журналы

Каждый запуск создаёт папку `profiles/ac8-build25201480-r8/evidence/session-...`. В ней автоматически сохраняются настройки опыта, события меню, нативные проверки, Steam-события, позы, задержки и результат удаления. При выходе из игры создаётся ZIP в `profiles/ac8-build25201480-r8/reports`. Кнопка «Сохранить отладочный отчёт» создаёт снимок текущих журналов без выхода; путь указан в `latest-debug-report.json` внутри сессии.

Архив содержит манифест с хешами каждого включённого файла и перечень пропусков, если живой файл нельзя прочитать или превышен предел размера. Игровой EXE, DLL и дампы памяти в отчёт не включаются. В отчёте могут быть SteamID участников и адреса объектов исследовательской сессии. Автоматической отправки куда-либо нет. Для разбора совместного опыта нужны отчёты с обеих машин.

## Границы проверки

В разработческом процессе проверены наличие кнопки в штатном списке, открытие страницы, ввод SteamID, отказ при пустом ID и возврат. В отдельном запуске r8 кнопка появилась автоматически без F8; создание отчёта по кнопке и при выходе проверено. Игра завершилась с кодом 0, временный загрузчик удалён. Исправление временного сообщения во время инициализации меню проверено автономно; отдельный повторный запуск с этим исправлением не проводился. Сетевой полёт с двух ПК через это меню требует отдельной живой проверки. Это прототип отображения второго самолёта: совместная миссия, ИИ, оружие, урон и результат кампании пока не синхронизируются.

Если страница показывает ошибку, сохраните отчёт. При `quarantine` штатно закройте игру. После выхода launcher снимает временный проверенный загрузчик; неизвестные DLL не удаляются.
