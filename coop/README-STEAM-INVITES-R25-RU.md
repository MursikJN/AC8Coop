# Steam-приглашения r25

Один комплект для обоих игроков, build 25201480. В штатном экране «Совместная игра» у хоста добавлена кнопка **«Пригласить друга»**. Она открывает обычный список друзей Steam; выбранному другу отправляется приглашение в нашу комнату. Гость принимает его средствами Steam, после чего мод сам подключается по SteamNetworkingSockets и открывает комнату. Ввод SteamID не требуется; ручной способ сохранён.

1. Оба распакуйте `ac8-steam-lobby-r25.zip` в отдельные папки, например `C:\AC8Coop-r25`. Не копируйте файлы в каталог игры. Закройте старые запуски обычным выходом и дождитесь завершения их лаунчеров.
2. Оба заранее запускаете игру через этот лаунчер: хост — `Start-Host.cmd`, гость — `Start-Guest.cmd`. При другой установке: `-GameDirectory "D:\путь\Game\Binaries\Win64"`. Оба входите в свои аккаунты Steam, уже добавленные друг другу в друзья.
3. Нажмите Enter на титульном экране и дождитесь главного меню. Гостю создавать комнату или вводить ID не нужно.
4. Хост: «Совместная игра» → «Создать лобби» → параметры → «Создать» → **«Пригласить друга»**. В появившемся штатном списке Steam выберите друга и отправьте приглашение.
5. Друг принимает приглашение в Steam. Мод проверяет его формат и Steam-друга, затем открывает гостевую комнату. Если приглашение принято до главного меню, подключение ждёт его загрузки. Если открыта другая комната, её транспорт сначала закрывается, затем начинается новое подключение. Повторное принятие для уже подключённого хоста не снимает готовность.
6. Дождитесь появления обоих имён, выберите F-14D на стороне гостя и подтвердите готовность с обеих сторон. Готовность отображается после ответа хоста.

Оверлей Steam должен быть доступен в запущенной игре. Если открыть список не удалось, интерфейс сообщает об этом; остаётся вход по SteamID64 хоста. Само открытие списка ещё не означает отправку приглашения или успешное подключение. Не отправляйте другу приглашение в обычный встроенный мультиплеер игры: используется кнопка нашего лобби. Запуск закрытой игры по приглашению пока не поддерживается — оба запускают r25 заранее.

Пока доступны задание 6, четыре штатных названия сложности и F-14D гостя. Две готовности **не запускают общую миссию**: клиентский мир, полёт гостя и общий запуск остаются отдельной работой. r25 добавляет приглашение и вход в лобби, не подменяет их доказательством кооперативного полёта. Состояние лобби остаётся совместимым с payload v3 r24, но для приглашений обоим нужен r25. Старые r11b не используйте.

«В главное меню» сохраняет комнату, «Выйти из лобби» закрывает транспорт. Журналы — `evidence/session-<дата-время>-<роль>/mod`, в том числе `steam-invite-events.tsv`, `steam-invite-status.tsv`, `steam-menu.log` и события соединения. После обычного выхода лаунчер собирает архив в `reports` и удаляет только свой временный загрузчик. Во время игры отчёт можно собрать `Collect-CoopLogs.ps1`, передав SessionDirectory и ReportsDirectory. В отчётах есть SteamID и имена; сохранения и резервные копии туда не входят.

Используется отдельный `userdata`, оригинальные SaveGames/Config клонируются при первом запуске и резервируются в `save-backups`. Не закрывайте окно лаунчера раньше игры. Пакет и игра проверяются по хешам; наличие чужого загрузчика останавливает запуск.

Автономные проверки охватывают callback ABI, формат приглашения, отправителя, повторы, очередь, разрешение открыть список только хосту и автоматический маршрут до гостевой комнаты. Живое принятие приглашения и подключение второго аккаунта требуют проверки с другом; результаты локального открытия списка фиксируются отдельно.
