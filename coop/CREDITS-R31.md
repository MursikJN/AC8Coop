# Компоненты и статус

AC8Coop — экспериментальная разработка в репозитории MursikJN/AC8Coop.
Код и документация подготовлены с участием OpenAI Codex; результаты игровых
проверок указаны отдельно. AI-генерация изображений/звука здесь не использовалась.

- UE4SS: UE4SS-RE/RE-UE4SS. Поставляется закреплённая ранее проверенная сборка
  3.0.1-1181-g83330635 и её файл лицензии `runtime/LICENSE`.
- Steam API вызывается через установленную пользовательскую библиотеку Steamv157.
  Игровой steam_api64.dll и игровые ресурсы в комплект не включены.
- Ghidra и GhidraMCP использовались для локального статического исследования;
  декомпиляция и оригинальные игровые файлы в комплект не включены.
- Owner-Lab-Peer.exe — собственный вспомогательный процесс AC8Coop для loopback,
  не исполняемый файл игры и не замена её физики.

Это локальная диагностическая поставка. Она не добавляет лицензию на игру
или разрешение распространять её ресурсы. Права на сторонние компоненты
сохраняются за их авторами; новую лицензию исходникам проекта этот файл
не назначает. Предварительный релиз предназначен для экспериментальных тестов;
успешный совместный полёт на двух ПК ещё не подтверждён.
