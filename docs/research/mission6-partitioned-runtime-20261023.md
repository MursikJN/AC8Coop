Сборка 25201480, отдельная копия игры и отдельный профиль сохранений. Steam Offline
подтверждён пользователем. Использован наблюдатель `ac8-mission6-capture-v2`;

## Проход

Видимое окно, штатные меню и клавиатурный ввод: титульный экран → Кампания →
свободный выбор → «Пилот» → задание 06 → «Сюжет» → брифинг → ангар → вылет →
обучение дозаправке → штатный пропуск дозаправки → основная миссия → пауза.
Рекс: F/A-18C, Бакстер: F-14D, Таша: F-35C, Коустер: Rafale M.
Все ведомые — штатные AI; мод не создавал и не подменял самолёты.

Меню пройдено без ручных нажатий пользователя. Надёжный ввод: universal-modder
WinDrive, `scanmode on`, удержание клавиши 150 мс, для пропуска дозаправки Esc
1200 мс. Перед действием проверялся снимок окна через Sky. Нажатие мышью по
строке самолёта один раз подтвердило предыдущий выбор; выбор исправлен стрелками
и проверен на итоговом экране звена. Для этого меню предпочтительна клавиатура.

## Границы доказательств

Каждый снимок читает один заново найденный объект; ссылки на другие UObject
записаны, но их свойства рекурсивно не читаются. `traversal_finished` относится
только к этому корню. Общего атомарного снимка мира и полноты native-полей нет.
Контейнеры с 1068 и 1088 записями дали частичные снимки из-за лимита времени;
их нельзя считать полностью прочитанными. В них наблюдались радиодействия и
условия говорящего/состояния ведомого; точная ресурсная привязка не доказана
для оборванных файлов.

Числа и ссылки выше не доказывают отправку EventHash по сети, применение команды
Бакстеру или возможность безопасно заменить AI. Следующая точечная проверка:
прочитать свойства уже найденных исполнителей/условий и их ресурсных источников,
связать ключ map → действие → target/pilot, затем сравнить до и после команды
ведомому и штатного перезапуска. ТЗ реализации пока не изменяется.
