# Локальная проверка жизненного цикла, 23 октября 2026

## Результат

Последовательный запуск двух настоящих процессов проверен: сначала хост дошёл
до главного меню, затем был запущен гость. Гость установил локальное соединение
протокола 8, но не дошёл до главного меню из-за ошибки памяти. Проверка двух
игровых сцен, брифинга, ангара и вылета **не завершена**.

Это отдельный исследовательский профиль, не обновление комплекта r31.
Он включает действующее ядро протокола и наблюдатель UE, но не включает
производственные адаптеры переходов, паузы катсцены или замены самолёта.
Наличие двух процессов и TCP-соединения не означает общий мир.

## Что проверено автономно

`scripts/Build-LifecycleLab.ps1` собрал DLL с текущими cinema/session policy
флагами и выполнил 842 проверки четырёх нативных наборов: 382+114+177+169.

`coop/lifecycle_lab.py` запускает два отдельных процесса Python, каждый
загружает настоящую DLL моста. Обмен идёт через TCP на 127.0.0.1, без Steam.
Результат `build/lifecycle-trial-01/result.json`: PASS для восьми сценариев:

- изменение миссии сбрасывает готовность; устаревшая команда отклоняется;
- задержка загрузки и истечение согласованного времени перехода;
- досмотр одного участника ждёт второго, два голоса за пропуск, старый ID сцены;
- новая готовность в ангаре, сброс после смены самолёта, один вылет на поколение;
- обрыв в полёте останавливает сессию;
- обрыв в лобби и при загрузке;
- отмена гостем.

Задержки относятся к подтверждениям клиента. Повторы проверены на уровне
команд/ревизий; это не испытание дублирования сырых TCP-пакетов. UE-события
в этих тестах задаются тестовым кодом: `gameplay_tested=false`. Изображение,
звук, физика и реальное переключение игровых экранов ими не подтверждаются.

Повторить без запуска игры, из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-LifecycleLab.ps1
.venv/Scripts/python.exe coop/lifecycle_lab.py test build/lifecycle-trial-02
```

Каталог результата должен быть новым. Для наблюдения состояния запущенного
моста: `coop/lifecycle_lab.py status <папка-роли>`; команды `cmd` адресованы
протоколу и сами не управляют игровым меню.

## Реальный запуск двух копий

Сессия: `pair-20261023-020403`, изолированный компактный EXE сборки 25201480.
Хост PID 26792, гость PID 15680. Steam оставлен в ранее подтверждённом
автономном режиме; транспорт только loopback, профили сохранений раздельные.

Хост запущен 02:04:03 UTC. После окончания стартовой загрузки главное меню
подтверждено изображением. Через штатное меню хоста выбраны НИЗКОЕ качество
и 30 FPS, счётчик показывал 29–30. Гость запущен около 02:12 UTC, только
после файла-подтверждения `start-guest` с текстом `main_menu_observed`.
Это ручной контроль наблюдаемой готовности, не автоматическое определение
окончания компиляции шейдеров.

Окна имели клиентскую область 960×540, но штатные настройки показывали
3440×1440 и безрамочный режим: размер окна не доказывает внутреннее разрешение.
Профиль перезаписал стартовые правки INI. У хоста низкое качество и лимит
подтверждены UI и сохранённым INI; у гостя они до аварии не подтверждены.

В обоих мостах наблюдались `transport=connected`, `phase=0`, `protocol=8`.
При загрузке гостя возникли:

- PowerShell: `System.OutOfMemoryException` при инициализации `TextWriter`;
- диалог игры о нехватке видеопамяти, затем `Error 01`;
- CIM: RAM 16 698 504 KiB, свободно 3 572 372 KiB; общий виртуальный
  лимит 62 353 664 KiB, свободно только 124 436 KiB (примерно 122 MiB).

Это свидетельствует об исчерпании системного лимита выделения памяти вместе
с графической ошибкой. Отдельная причина потребления/пиковый запрос не найдены.
Видеоадаптер — Radeon RX 9070 XT. Поле AdapterRAM из CIM не использовалось
как размер VRAM: его 32-битное значение ненадёжно. Одно измерение до гостя
показывало 6 177 615 872 байт выделенной GPU-памяти; пиковое не получено.

После подтверждения аварийного выхода гостя и обычного Alt+F4 хоста:
host_exit=0, guest_exit=3, proxy_removed=true, конец 02:16:02 UTC. Оба
процесса отсутствуют. После выхода свободная виртуальная память восстановилась
до 35 366 140 KiB. Размер файла подкачки и чужие приложения не менялись.

## Исправление подготовки и ограничения

Следующий запуск гостя будет брать отдельную копию SaveGames/Config из уже
настроенного изолированного профиля хоста: игра восстанавливает графику из
System.sav поверх INI. Добавлено явное поле outcome для ненулевых кодов выхода.
Эти изменения прошли разбор PowerShell и preflight без запуска игры;
повторный запуск двух игр после исправления **не выполнен**.

Наблюдатель `probe/LifecycleLab/Scripts/main.lua` читает UE на игровом потоке.
Поле main_menu осталось 0 при визуально открытом меню: проверка
IsVisible+IsInViewport не подтверждена для вложенных виджетов. Нельзя
использовать этот флаг как автоматический допуск перехода до исправления
и сопоставления с реальными экранами. Записи наблюдателя не заменяют снимки UI.

Для повторяемой подготовки профиля нужен существующий
`profiles/ac8-lifecycle-pair-v1/profile-manifest.json`; профиль содержит
локальные бинарные зависимости и не является публичным дистрибутивом.
Preflight: `scripts/Start-LifecyclePair.ps1`. Реальный запуск требует
`-Launch -SteamOfflineConfirmed`, контроля первой загрузки и отдельного
подтверждения `start-guest`. Сам preflight игру не запускает.

Следующий практический шаг — проверить расход памяти одной копии при
действительно низком разрешении и сохранённых настройках, затем оценить запас
для второй. Пока надежнее продолжать протокольные сценарии без второй игры;
для проверки двух полноценных сцен использовать второй ПК. Синхронные
катсцены/загрузка/полёт в реальном движке остаются открытой проверкой.
