# r28 — состояние на 21 октября 2026

Запрос: катсцены локально с изображением/звуком; пропуск по двум голосам;
при разном времени просмотра ожидать обоих; игру не запускать до следующей проверки.

## Изменения

`AC8_CINEMA_SYNC_R28` включает протокол 6, отдельные приглашения v6/порт 390.
Основная DLL по-прежнему содержит один Steam worker. Надёжный ограниченный канал
AC8C передаёт только локальные пути ресурсов, вид плеера и длительность. SteamID,
два nonce и последовательность проверяются до передачи данных в Lua. Пути не
являются URL, командами, Lua-кодом, UObject-адресами или обработчиками событий.
Worker не обращается к движку. Идентификатор подготовленной сцены неизменяем.

В SharedSession добавлены cinema_prepared / cinema_finished / cinema_committed,
состояния prepare → armed → playing → exit_armed → exit и два барьера с дедлайном
хоста. Пропущенный дедлайн без обоих подтверждений переносится. Обычное завершение
одного игрока не меняет этап. SceneEnded и следующий SceneSegment блокируются,
пока не согласован выход и не получены оба терминальных подтверждения. Для начальной
загрузки требуются реальные prepared receipts. Старая эпоха, сцена и редакция отклоняются.
Гость не меняет авторитетный снимок спекулятивно по локальному таймеру; только
воспроизведение использует уже подтверждённый общий дедлайн.

cinema_playback.lua связывает два местных плеера с барьерами. На терминальном
участке (осталось ≤250 мс по native timeline) плеер приостанавливается до второго
участника. Это точка готовности к окончанию, не доказательство вызова native OnFinished.
После общего отпускания хвоста адаптер хоста отдельно ждёт штатного конечного экрана.
При голосовании host stock skip guard разрешается только после двух голосов и общего
exit deadline; гость завершает только свой плеер. Прямого вызова перехода кампании гостем нет.

cinema_native.lua содержит кандидаты для LiveManaMovieViewer и родного LiveCinematics
factory. Mana проверяет реальную текстуру, decoder readiness и выбранные дорожки;
Sequence требует реальный asset с Options, камеру и bDisableGameProcess=true.
Пустой generic LevelSequencePlayer, экран ожидания и таймер не считаются сценой.
Гость восстанавливает прежнюю камеру и удаляет только собственное представление.

## Границы доказательства

Автономные тесты подтверждают алгоритм и вызовы подставных UObject API. Они не
подтверждают воспроизведение в ACE COMBAT 8. Точная семантика bDisableGameProcess,
native OnFinished=nil в bundled UE4SS, фактические Options/ресурсы роликов,
совместимость фабрики виджета, звук и пауза в брифинге остаются непроверенными.
Если Options лежат в закрытом реестре/строке таблицы и не находятся отражением
как доступный ресурс, адаптер остановится с причиной; это ещё нужно будет привязать.
Обычный MediaPlayer/LiveMovieViewer и озвученное UI без одного из этих плееров
в данной реализации не объявляются поддержанными.

Игровые файлы/процессы не изменялись. Игра, Steam-сессия и друг для тестов не запускались.
Сборка r27 и её архив сохраняются отдельно. Полная репликация миссии и первый
совместный полёт по-прежнему не приняты.
