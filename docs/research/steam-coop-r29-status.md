# r29 — 21 октября 2026

По запросу пользователя: прогресс только хосту, вход только из лобби, сброс
готовности, отмена зависшей загрузки, потеря связи и общий перезапуск. Игра не запускалась.

## Реализовано

- Протокол 7 (320 байт), приглашения v7, порт 391. Приём Steam connection
  проверяет stage==lobby до AcceptConnection; Lua также не переключает миссию
  по новому приглашению. Роль Lua/native закреплена лаунчером.
- Изменения loadout ревизируются; старый Ready отклоняется. Неизменившиеся
  настройки идемпотентны. Уход хоста с Standby на редактирование сбрасывает
  готовности, самолёт хоста перечитывается перед запуском.
- Отдельная очередь cancellation/fault обходит неподтверждённый обычный intent.
  Неподтверждённый старый ACK не подтверждает новую отмену. Команды привязаны к
  token/epoch/revision/generation; отмена той же попытки допускается через границу загрузки.
- Worker watchdog использует монотонные часы, 120 с без реального прогресса.
  Повторная арматура дедлайна/heartbeat не продлевают ожидание. Ручной ангар не
  ограничен таймером; длинный непрерывно играющий ролик тоже.
- Disconnect вне лобби останавливает попытку, очищает барьеры и меняет поколение.
  GT удерживает мир до отключения pilot/role/client/cinema. Устаревшее локальное
  состояние блокирует ввод и переходы. UI восстановления добавлен как кандидат.
- Host userdata постоянна, guest userdata уникальна для каждого session directory.
  Гостевой прогресс не экспортируется в исходный или следующий гостевой профиль.
- Общий restart: остановка обоих → loading/commit barrier → подтверждение гостя
  → долговечный одноразовый план → штатный QuitGame → проверенный launcher re-entry.
  Принятое конечное решение переживает ожидаемый выход первого участника.
  Новая игра возвращается в лобби без автоматической готовности.

## Существенные ограничения

Замена Бакстера r19 однократная. **Внутрипроцессный Retry и checkpoint restore
не реализованы.** Рабочий путь, подготовленный в этой версии, использует чистые
процессы и полный маршрут через лобби. Титульный Enter остаётся штатным ручным вводом.
Это не следует называть мгновенным общим перезапуском миссии.

PowerShell тесты доказывают изоляцию путей и политику билетов на искусственных
сохранениях. Они не доказывают поведение сохранений/Steam Cloud самой игры.
Новые native QuitGame/пауза/кнопки и повторный вход не проверялись в игре.
Репликация оружия, урона, всех событий миссии, клиенты AV/карта остаются незавершёнными.

Исправлены обнаруженные при работе ошибки: лишний текст на строке #endif в
проверке native диапазона команд; отсутствие пути menu-route DLL в Steam main;
старое connected после несовместимого status; обработка CRLF native status в restart
validator. Для восстановления не обнуляются one-shot ledgers и не обходятся их проверки.

`docs/research/steam-coop-r29-validation.json`.
