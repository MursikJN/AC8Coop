# Разработка и воспроизводимость

Публикация — исходный снимок лаборатории. Большинство живых скриптов пока привязаны к `D:\projects\unreal-mod-tools`, профилю `ac8-build25201480`, известной сборке игры и проверенным хешам. `C:\Users\USER` в исторических файлах — заменённый личный путь, не готовая настройка. Скрипты с PID/адресами старой сессии служат материалами исследования, запускать их для нового процесса нельзя.

## Проверки без запуска игры

Используется Python 3.11+ и Lupa 2.6. Из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

Capstone нужен скриптам статического анализа. Некоторые исторические тесты добавляют старую локальную папку в sys.path; установленные в venv пакеты всё равно доступны. Тесты моделируют память/вызовы и не создают самолёт в игре.

Для нативного полётного модуля нужны Windows x64 и Visual Studio Build Tools с C++:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-PlaneFlightProbe.ps1 -OutputRoot "$PWD/build/plane-flight"
```

Команда собирает r4 и выполняет нативные проверки без старта игры. Результат сборки не устанавливается автоматически. Хеш DLL может отличаться от исторического, в том числе из-за пути сборки. Launcher использует закреплённый хеш; согласовать новый артефакт и профиль нужно отдельно, не отключая проверки вслепую.

Для `Build-ConnectionTest.ps1` отдельно нужны заголовки Valve GameNetworkingSockets указанной в THIRD-PARTY ревизии; путь передаётся через `-ValveHeaders`. Они и UE4SS не включены в Git.

## Живой запуск

Нужны собственная установленная игра точной сборки, Steam, подготовленный профиль UE4SS, собранная DLL и согласованные пути/хеши. `Start-PlaneFlightProbe.cmd` из папки scripts рассчитан на установку рядом с профильным `Launch-Recon.ps1`, а не на запуск прямо из произвольного checkout. Универсальный установщик пока не сделан.

Публичный Connection Test больше не содержит ваших SteamID: launcher спрашивает ID второго участника, упаковщик создаёт пустые поля peers. Числа в mock-тестах синтетические. Существующий персональный архив 0.1.2 и установленные настройки участников этой публикацией не менялись.

## Состав сохранения

Код и инструкции опубликованы полностью в объёме лаборатории. Игровой EXE, DLL игры, ассеты, сырые дампы/снимки, журналы с личными данными, сторонние SDK/инструменты и скомпилированные пакеты остаются локально. Вместо сырых записей включены отобранные технические результаты. Исторические ссылки на отсутствующие локальные материалы не означают, что эти материалы доступны на GitHub.

Репозиторий открыт для просмотра. Отдельное разрешение на распространение авторского кода пока не оформлено лицензией; лицензии сторонних проектов не распространяются автоматически на этот проект.
